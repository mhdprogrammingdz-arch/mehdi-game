MEHDI BRAIN CHALLENGE
=====================

هذه الحزمة مأخوذة من مستودع المشروع الحالي، وتتضمن واجهة اللعبة وملفات Edge Function وملف ترحيل قاعدة البيانات.

1) تشغيل اللعبة
- فك ضغط الملف كاملاً.
- افتح index.html باستخدام Chrome أو Edge.
- يلزم اتصال بالإنترنت لاستخدام Supabase وتسجيل اللاعبين وتشغيل الجولات ولوحة النتائج.

2) اتصال Supabase الحالي
- المشروع مرتبط مسبقاً بالمشروع:
  https://mqibocnozcfagrvxkxbr.supabase.co
- مفتاح المتصفح الموجود في index.html هو Publishable Key، وهو مخصص للاستخدام في الواجهة.
- لا تضع SUPABASE_SERVICE_ROLE_KEY داخل index.html أو أي ملف يوزع على اللاعبين.
- تحفظ مفاتيح الخادم في إعدادات Supabase Edge Functions فقط.

3) نشر وظيفة اللعبة عند الحاجة
من داخل مجلد المشروع الذي يحتوي على مجلد supabase نفّذ:
  supabase functions deploy brain-game

4) قاعدة البيانات
- هذه النسخة تستعمل قاعدة بيانات Supabase الحالية ولا تنشئ قاعدة جديدة تلقائياً.
- لا تحذف الجداول ولا تعِد تهيئة قاعدة البيانات.
- ملف supabase/migrations/20261108_unique_player_nicknames.sql مرفق كمرجع لترحيل فهرس الأسماء الفريد؛ لا تعِد تشغيله عشوائياً على قاعدة البيانات الحالية.
- الأسئلة واللاعبون والجولات والنتائج تبقى في مشروع Supabase الحالي، ولا تُخزّن داخل ملف ZIP.

5) مجال الأصدقاء
- الأسئلة غير المستهلكة للشخص المختار تُستخدم أولاً.
- بعد استهلاك أسئلة الشخص، تبدأ جولة جديدة من أسئلته بترتيب عشوائي.
- لا يتم حذف أسئلة أو لاعبين أو نتائج عند بدء دورة جديدة.

مهم
- ملف ZIP لا يحتوي على مفتاح الخدمة السري.
- لا تشارك أي Service Role Key أو كلمة مرور مع أي شخص.
